# 长笛、双簧管与钢琴：室内乐工作总谱

这是六乐章的改编起点：长笛、双簧管暂为逐小节休止，钢琴采用 `../piano/lilypond/movements/` 的现有工作稿。小节号在每个乐章内从 1 开始；Forlane 第 140 小节的两个分支沿用钢琴稿的编号方式。

- `score.ly` 是总谱入口；`output/score.pdf` 是总谱。
- `winds/*.ily` 按乐章保存长笛和双簧管声部，供后续逐小节改编。
- `piano/*.ily` 是钢琴稿的独立副本，音符及标记沿用原工作稿；为适应总谱移除了钢琴独奏谱的强制换行。
- `output/score.midi` 包含长笛、双簧管和钢琴三个乐器轨，以及 MIDI 所需的速度轨。当前两个管乐器轨为空，钢琴的左右手共用一个轨道。

需要 LilyPond（以 2.26.0 验证）和 Python 3。在仓库根目录运行：

```sh
python3 fl-ob-piano/build.py
```

此命令只生成总谱和全曲 MIDI。钢琴声部继承原稿尚未逐音精校的限制，详见 `../EDITORIAL.md`；MIDI 的印刷反复线尚未展开。
